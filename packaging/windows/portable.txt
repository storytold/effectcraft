Visualab Effects portable mode

While this file sits next to effectcraft.exe, Visualab Effects keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the Visualab EffectsData folder beside it instead of
%APPDATA%\Visualab Effects. Copy the whole folder to move Visualab Effects with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\Visualab Effects unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\Visualab Effects) instead.
If Visualab EffectsData can't be written (for example on a read-only drive), Visualab Effects logs a
warning and uses %APPDATA%\Visualab Effects instead.
