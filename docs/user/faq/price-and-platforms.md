Yes, EffectCraft is free. It is open source, dual-licensed under MIT or Apache-2.0, at your option. It has no telemetry, and it uses no network access unless you ask for it.

## Where it runs

| Platform | Builds                                                                                 |
|----------|----------------------------------------------------------------------------------------|
| Windows  | x64, arm64 and 32-bit x86, as MSI installers and portable zips                         |
| macOS    | One universal app for Apple silicon and Intel                                          |
| Linux    | x86_64 and aarch64 as AppImage, Flatpak, deb, rpm and tar.gz; riscv64 deb, rpm, tar.gz |
| FreeBSD  | x86_64 tar.gz                                                                          |
| Browser  | A web build that runs the full app                                                     |

See [Install EffectCraft](../getting-started/install.md) for the files.

## How mature is it?

EffectCraft is in alpha. The README calls macOS the most tested platform, and says Linux and Windows users have hit basic interaction bugs that are being fixed first. Bug reports in the [issue tracker](https://github.com/storytold/effectcraft/issues) are the most useful thing you can send.
